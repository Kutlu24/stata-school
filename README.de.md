# Stata Okulu — Stata-Lernressource

Eine statische, türkischsprachige Referenzseite zum Erlernen von **Stata**, der in Wirtschaftswissenschaften und Sozialwissenschaften weit verbreiteten Statistiksoftware. Enthält Kursübersichten, Befehlsanleitungen und lauffähige Codebeispiele.

🇬🇧 English version: [README.md](README.md)

## Was es macht

- **Kurslar (Kurse):** drei Kursreihen (Grundlagen, Fortgeschritten, Spezialthemen) mit echten, lektionsweisen Übersichten, umschaltbar per Button.
- **Rehberler (Anleitungen):** Kurzreferenz-Karten — Datenimport, deskriptive Statistik, Datenbereinigung, Grafiken.
- **Örnekler (Beispiele):** zwei durchgerechnete Codebeispiele (einfache lineare Regression, gruppierte deskriptive Statistiktabelle) mit echter Stata-Syntax.
- **Kaynaklar (Ressourcen):** Links zur offiziellen Stata-Dokumentation, den UCLA-IDRE-Stata-Ressourcen und dem Statalist-Community-Forum.
- Animierter Hintergrund mit durchlaufenden Stata-Befehlsnamen, rein dekorativ.

## Technik

Reines HTML, CSS und Vanilla-JavaScript. Icons über [Font Awesome](https://fontawesome.com/) (CDN).

## Ausführen

`index.html` im Browser öffnen, oder den Ordner mit einem beliebigen statischen Server bereitstellen:

```bash
npx serve .
```

## Hinweise

Die ursprüngliche Quelle enthielt nur Abschnittsüberschriften mit `<!-- ... -->`-Platzhalterkommentaren, aber keinen echten Inhalt. Kursübersichten, Anleitungskarten, Codebeispiele und Ressourcenlinks wurden vor der Veröffentlichung verfasst.
