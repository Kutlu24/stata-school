Hoş Geldiniz

Stata Okulu'na hoş geldiniz! Bu sitede istatistiksel yazılım Stata'yı sıfırdan öğrenmek için ihtiyacınız olan temel kursları, komut rehberlerini ve çalışan kod örneklerini bulacaksınız. İçerik, sosyal bilimlerde ve ekonometri derslerinde en sık kullanılan komutlar etrafında düzenlenmiştir.

Rehberler

Veri İçe Aktarma

Excel, CSV veya başka bir Stata veri setini çalışma alanına yükleme.

import excel "veri.xlsx", sheet("Sayfa1") firstrow clear
import delimited "veri.csv", clear
use "veriseti.dta", clear

Temel Komutlar Referansı

describe          // Değişkenlere genel bakış
summarize gelir   // Betimsel istatistikler
tabulate cinsiyet // Frekans tablosu
list in 1/10      // İlk 10 satırı göster
browse            // Veri tarayıcısını aç

Veri Temizleme

drop if gelir == .          // Eksik gözlemleri at
rename eskiisim yeniisim    // Değişken adını değiştir
recode egitim (1/3=1) (4/6=2), gen(egitim_grup)
label define grup 1 "Düşük" 2 "Yüksek"
label values egitim_grup grup

Grafik Çizimi

histogram gelir, normal
graph twoway scatter gelir egitim_yili
graph export "grafik.png", replace

Örnekler

Basit Doğrusal Regresyon

Gelir üzerinde eğitim yılı ve deneyimin etkisini test eden bir regresyon modeli:

regress gelir egitim_yili deneyim
* Standartlaştırılmış katsayılar için:
regress gelir egitim_yili deneyim, beta
* Model uyum iyiliği ve artıkların incelenmesi:
predict artik, residuals
histogram artik, normal

Gruplara Göre Betimsel İstatistik Tablosu

Bir kategorik değişkene göre ortalama/standart sapma tablosu oluşturmak:

tabstat gelir egitim_yili, by(bolge) statistics(mean sd n) columns(statistics)
* Aynı tabloyu dışa aktarmak için:
tabstat gelir, by(bolge) save
collect layout, formatoptions(sspace hspace(2))
