Guides

Importing Data

Load an Excel file, CSV, or another Stata dataset into your workspace.

import excel "data.xlsx", sheet("Sheet1") firstrow clear
import delimited "data.csv", clear
use "dataset.dta", clear

Core Command Reference

describe          // Overview of variables
summarize income  // Descriptive statistics
tabulate gender   // Frequency table
list in 1/10      // Show first 10 rows
browse            // Open the data browser

Cleaning Data

drop if income == .          // Drop missing observations
rename oldname newname       // Rename a variable
recode education (1/3=1) (4/6=2), gen(edu_group)
label define grp 1 "Low" 2 "High"
label values edu_group grp

Plotting

histogram income, normal
graph twoway scatter income years_educ
graph export "chart.png", replace

Examples

Simple Linear Regression

A regression model testing the effect of education and experience on income:

regress income years_educ experience
* For standardized coefficients:
regress income years_educ experience, beta
* Checking model fit and residuals:
predict resid, residuals
histogram resid, normal

Descriptive Statistics Table by Group

Building a mean/standard-deviation table by a categorical variable:

tabstat income years_educ, by(region) statistics(mean sd n) columns(statistics)
* To export the same table:
tabstat income, by(region) save
collect layout, formatoptions(sspace hspace(2))
